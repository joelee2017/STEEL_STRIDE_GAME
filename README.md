# STEEL STRIDE｜鋼鐵步兵

**2D 橫向機甲動作射擊遊戲**

駕駛機甲投入戰場，運用移動、跳躍、衝刺與射擊，在不同戰場目標中迎戰敵人。

## 遊戲介紹

STEEL STRIDE 是一款以瀏覽器為平台的 2D 機甲射擊遊戲。

遊戲以機甲戰鬥為核心，結合靈活的移動操作、即時射擊與關卡挑戰，持續擴展戰場上的戰鬥體驗。

## 遊戲特色

- **機甲戰鬥：** 操作機甲進行移動、跳躍、衝刺與射擊。
- **即時交戰：** 在戰鬥中應對敵人攻擊，掌握移動與進攻時機。
- **多樣關卡目標：** 挑戰敵人清除、生存與突破任務。
- **持續擴展：** 逐步加入更多敵人類型與戰鬥挑戰。
